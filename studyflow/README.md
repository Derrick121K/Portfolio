# StudyFlow — Student Assignment Deadline Planner

A responsive, interactive academic task planner developed for the HCN6222 Portfolio of Evidence.

Live website: https://derrick121k.github.io/Portfolio/studyflow/
Source code: https://github.com/Derrick121K/Portfolio/tree/main/studyflow

## Run locally
Open index.html in a current browser, or serve this folder with:
python -m http.server 8000
Then visit http://localhost:8000. No package installation is required.

## Files
- index.html — semantic page structure and StudyFlow screens.
- styles.css — responsive navy, purple and white interface.
- app.js — task management, search, filters, calendar, peer plan sharing, browser reminders, accessibility controls and JSON backup/restore.

## Prototype boundaries
Task data is stored locally in the current browser. Browser notifications require HTTPS or localhost, user permission, and the StudyFlow page to remain open. Peer sharing creates a copyable study-plan summary; it is not a multi-user cloud collaboration service. No backend, account service or cloud synchronisation is connected.
